# Three in a Row: Roguelike Crystals

[![Build and release](https://github.com/sergeiwork/3-in-a-row/actions/workflows/build-release.yml/badge.svg)](https://github.com/sergeiwork/3-in-a-row/actions/workflows/build-release.yml)

Мобильный roguelike в жанре «три в ряд», где каждый собранный кристалл становится оружием. Игрок прокладывает маршрут по процедурной карте, сражается с противниками на поле 7×7 и собирает билд из пассивных улучшений и активных навыков.

Проект представляет собой играбельный вертикальный срез для Unity с портретным интерфейсом на русском языке, детерминированной симуляцией и локальным сохранением забега.

## Особенности

- Четыре типа обычных кристаллов с разными эффектами: прямой урон, Фокус, Токсин и сокращение перезарядки.
- Особые кристаллы за комбинации из четырёх и пяти элементов, включая Призму с очисткой цвета.
- Каскады, гравитация, пополнение поля и автоматическое перемешивание без доступных ходов.
- Пошаговые бои с заранее показанными намерениями противника.
- Статусы поля: заморозка, трещина и якорь — каждый со своим правилом и способом противодействия.
- Ветвящаяся карта из семи рядов с боями, событиями, отдыхом, элитным противником и одним из двух боссов.
- Двенадцать пассивных улучшений, пять активных навыков и четыре элитных ключевых улучшения.
- Воспроизводимые забеги на основе seed и независимых потоков случайных чисел.
- Сохранение и продолжение стабильного состояния забега.
- Адаптивный портретный UI, управление касанием или свайпом и режим уменьшенного движения.

## Технологии

- GitHub Actions и GameCI

## Как запустить

1. Установите Unity Hub и редактор Unity `6000.5.7f1`.
2. Клонируйте репозиторий:

   ```powershell
   git clone https://github.com/sergeiwork/3-in-a-row.git
   cd 3-in-a-row
   ```

3. Добавьте папку проекта в Unity Hub и откройте её указанной версией редактора.
4. Откройте сцену `Assets/Game/Scenes/PortraitGame.unity`.
5. Нажмите **Play**.

Готовые сборки для Windows x64 и Android публикуются в разделе [Releases](https://github.com/sergeiwork/3-in-a-row/releases). Сборки из обычных коммитов также доступны как артефакты соответствующего запуска GitHub Actions.

## Управление

- Выберите два соседних кристалла касаниями или проведите по кристаллу в нужную сторону.
- Перед ходом можно применить готовый активный навык.
- После допустимого хода поле полностью разрешает все каскады, затем выживший противник отвечает автоматически.
- Недопустимая перестановка отменяется и не расходует ход.

Правила кристаллов, статусов, навыков и ресурсов также доступны во внутриигровом разделе «Как играть».

## Тесты

Edit Mode-тесты покрывают правила поля, бой, прогрессию, карту, детерминизм и сквозные сценарии. Запустить их можно в Unity через **Window → General → Test Runner → EditMode → Run All**.

Для запуска из командной строки Windows:

```powershell
& "C:\Program Files\Unity\Hub\Editor\6000.5.7f1\Editor\Unity.exe" `
  -batchmode `
  -nographics `
  -projectPath $PWD `
  -runTests `
  -testPlatform EditMode `
  -testResults "Logs\editmode-results.xml"
```

Если Unity установлена в другую папку, замените путь к `Unity.exe`.

## Архитектура

Игровая логика отделена от Unity-представления и разбита на четыре слоя:

```text
Assets/Game/
├── Domain/          чистая C#-симуляция, состояние, команды, события и RNG
├── Application/     сценарий забега и координация игровых переходов
├── Infrastructure/  JSON-сохранения и интеграция с окружением
├── Presentation/    UI Toolkit, ввод, анимации, звук и визуальные эффекты
└── Tests/Editor/    детерминированные Edit Mode-тесты и сценарии
```

`Domain` и `Application` не зависят от Unity Engine. Представление отправляет команды и воспроизводит полученные события, но не вычисляет исход боя. Контент и сохранения используют стабильные строковые идентификаторы вместо Unity instance ID.

## Статус проекта

Текущая версия контента — `0.6.0`. Реализованы основной вертикальный срез и первые этапы расширения контента: разнообразие билдов и противников, ветвящиеся маршруты, события, элитные бои и альтернативный босс.

Следующий этап — балансировка контента на фиксированных маршрутах и проверка читаемости интерфейса на портретных экранах 16:9 и 20:9.
